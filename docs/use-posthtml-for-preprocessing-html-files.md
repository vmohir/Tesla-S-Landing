# Use PostHTML for Preprocessing HTML Files

## Context and Problem Statement

As we're not allowed to use any framework or library and we can only use pure HTML files,
we can only use preprocessors to reduce the repeated HTML codes.

## Considered Options

- Handlebars
- ejs
- PostHTML plugins
- Pug

## Decision Outcome

Chosen option: ejs + "PostHTML plugins", because it has the closest syntax to the HTML itself.
